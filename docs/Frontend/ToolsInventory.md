The parameter form is its own component, `VisualisationParameters`, shared by the dashboard and the Datasource builder's preview. |

## Graph analytics (Case Management theme)

The graph diagram in `Jube.Charting` now supports node groups with stable colours, dashed nodes, node and edge identities (`data-node`, `data-from`, `data-to`) for browser selection, a grid for unconnected nodes and a raisable extent. Next, for case graphs: force-directed layout, node size by centrality (degree, PageRank, betweenness), community colouring, neighbourhood expansion and time-ordered edges.

## Known issues found along the way

- `SchemaField` and `ValueGrid` showed date-times in UTC where the input is local time (fixed 2026-10-21 using `composables/localDateTime`).
- `ProblemAlert` and `describeApiError` are the pattern for error display in new work.
