# Slice review: admin-telemetry

Agent-mode review, 2026-11-08. Nothing was built and no dotnet test was run (owner's serial pass). Foundation,
login-audit, security-admin, models and cases slices are inherited.

## 1. Summary and verdict

Verdict: READY AFTER OWNER ACTIONS. Landlord-only enforcement is sound on every route and verb of all three areas
(Exclude, LogCounter, Metric): the service gate `EnsurePermitted` (landlord only, permissions list empty) runs first in
every operation and the endpoints return a bare 403. The real defects were elsewhere: the log-line regex hot path was
ReDoS-exposed (1 s timeout per rule per line, backtracking engine, every rule recompiled each minute), duplicate names
were allowed although the DTO says Unique, exclusion names accepted padding, bidi and look-alike characters, the page
had no landlord denial on deep link, and the local OTLP listener had a log-injection hole. All fixed. The audit trail
cannot be silenced by an exclusion (exclusions only drop instruments from the external OTLP metric export). Design
questions remain (section 3).

Before commit: owner runs the manual test (section 9); serial pass runs the dotnet tests in section 5; owner decides the
design items; locale integration pass; screenshots.
