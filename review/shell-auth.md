# Slice review: shell-auth

Agent-mode review, 2026-11-08. Steps 0, 2, 3, 4, 5. Nothing was built and no DB-backed or Playwright test was run. Late
scope additions are included: the required locale set is en, pl, ar, ka, id, sv, ur, hi.

## 1. Summary and verdict

Verdict: READY AFTER OWNER ACTIONS, with one real defect fixed. The slice is big (46 Vue files, 3 endpoint files, about
1400 lines of auth service) and its back-end security coverage is already strong (about 390 service tests and 53 pen
tests by script count, see matrix). The gaps found:

1. `GET /api/Me` always returned `tenantRegistryId: 0` (never populated), so `TenantSwitcher` for landlords never knew
   the current tenant. Fixed in `PermissionValidation`, 2 tests added (unrun).
2. `/api/Me` has no back-end test at all.
3. All server-side authentication messages (password rules, validator messages) are hard-coded English and there is no
   `AuthenticationResources` class, so there are no pl/ar/ka `.resx` to create. Left as an owner decision.
4. Georgian is not registered anywhere (SPA, server culture list); the font stack has no Mkhedruli face.
5. The shell statically imports the Ask Jooby widget (boundary recorded below).

Before commit: owner manual test (section 9); someone with a test database builds and runs
`PermissionValidationTenantTests` (Service) and the serial PenTest pass; owner decisions in section 11.
