# Slice review: model-abstraction

Agent-mode review, 2026-11-08. Steps 0, 2, 3, 4, 5. Nothing was built and no .NET or DB-backed test was run. The slice
has no Vue files, so npm format, eslint, type-check and vitest have nothing of this slice to check and were not run.

## 1. Summary and verdict

Verdict: READY AFTER OWNER DECISIONS and one serial test pass. The CRUD back end for the three areas (TTL counters,
abstraction rules, abstraction calculations) is well covered (service tests 52 + 59 + 12 + 45, PenTest through two
shared bases) and no cross-tenant, IDOR or mass-assignment hole was found. Three real defects were fixed and four engine
and platform issues were raised.

Answers to the brief:

1. **Expression compile and execution isolation.** Builder and Coder scripts are translated by `Jube.Parser` to a token
   allow-list, length capped at 65,536 (`RuleParse.MaximumRuleTextLength`), nesting depth capped at 64
   (`RuleParse.MaximumNestingDepth`), and compiled by Roslyn into an unloadable `AssemblyLoadContext`. Both validators
   run the parser on save (`RuleSet(RuleScriptParser.SaveRuleSets, ...)` contains "default", so Insert and Update
   compile the script). Covered by `RuleParseSecurityCorpusTests`, `RuleParseNestingDepthTests`, `RuleSandboxTests`,
   `AbstractionCalculationParityTests`. Open: `Compile.cs` logs the whole rule source at INFO, and `RuleSandbox`
   (execution timeout) is only used by the simulation runner (shared TODOs).
2. **TTL counter keys and tenant isolation.** Every cache key starts with tenant, model guid and counter guid
   (`CacheTtlCounterRepository`, `CacheTtlCounterEntryRepository`), so two tenants never share a counter. Abstraction
   cache key is `Abstraction:{tenant}:{modelGuid}:{SearchKey}:{SearchValue}`. Colons in a payload value cannot reach
   another tenant or counter.
3. **Overflow and negatives.** TTL interval value is capped per unit by `IntervalLimits` and tested by
   `PenTestModelTtlCounter.Window_TtlCounterValueCannotOverflowTheEngineDateMathsAsync`. Abstraction rule Search Value
   and Offset Value had NO upper bound: the engine calls `DateAndTime.DateAdd(unit, value * -1, date)`
   (`AbstractionWindow.FromDate`, `AbstractionRuleCaching.cs:379`), which throws for a few hundred million days, in the
   invoke path. Fixed (finding 1). Sum increments are not validated, so a negative payload value lowers a counter
   (documented, owner decision).
4. **Deprecation.** Read `TtlCounterDeprecationTimingTests` (13) and `TtlCounterModelSyncTests` (3) and the memory note.
   Coverage of s/n/h/d/m/y, live forever, zero interval, independent counters and unstarted models is thorough. Nothing
   added.
5. **Permissions.** 12 (TTL counter, plus 17 for read-by-model), 13 (rule), 14 (calculation), one set for list, read and
   write. Endpoint groups use `RequireAuthorization`. Existing matrix tests cover each verb.
